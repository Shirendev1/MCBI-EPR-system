# MCBI – Mongolia's EPR System
# MCBI – Монголын EPR систем

---

## Overview / Ерөнхий мэдээлэл

This repository contains foundational documents for developing a circular economy framework, battery waste management, and an Extended Producer Responsibility (EPR) system in Mongolia.

Энэ репозиторт Монголд тойрог эдийн засгийн тогтолцоо, батарейн хаягдлын менежмент болон үйлдвэрлэгчийн өргөтгөсөн хариуцлагын (EPR) системийг хөгжүүлэхэд зориулсан суурь баримт бичгүүд багтсан.

---

## Purpose / Зорилго

**English:**

To develop a responsible system for collecting, reusing, and recycling batteries and other waste in Mongolia. The system aims to support producer accountability, reliable data management, sustainable financing, infrastructure development, and environmentally responsible consumer practices.

**Монгол:**

Монголд батарей болон бусад хаягдлыг хариуцлагатайгаар цуглуулах, дахин ашиглах, дахин боловсруулах тогтолцоог хөгжүүлэх. Энэ тогтолцоо нь үйлдвэрлэгчийн хариуцлага, өгөгдлийн найдвартай удирдлага, тогтвортой санхүүжилт, дэд бүтцийн хөгжил болон байгаль орчинд ээлтэй хэрэглээг дэмжинэ.

## Core Concept / Гол санаа

**English:**

EPR connects producer responsibility, data governance, financing, infrastructure, and consumer participation across the product lifecycle. It helps define who is responsible for products and materials at each stage, including collection, reuse, and recycling.

**Монгол:**

EPR нь бүтээгдэхүүний амьдралын мөчлөгийн турш үйлдвэрлэгчийн хариуцлага, өгөгдлийн удирдлага, санхүүжилт, дэд бүтэц болон хэрэглэгчийн оролцоог уялдуулдаг. Ингэснээр бүтээгдэхүүн, материалыг цуглуулах, дахин ашиглах, дахин боловсруулах үе шат бүрд хэн ямар үүрэгтэйг тодорхойлох боломж бүрдэнэ.
