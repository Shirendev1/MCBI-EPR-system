# MCBI – Mongolia's EPR System
# MCBI – Монголын EPR систем

---

## Overview / Ерөнхий Мэдээлэл

This repository contains foundational documentation for implementing a circular economy framework, battery waste management, and Extended Producer Responsibility (EPR) system in Mongolia.

Энэ repository нь Монголд хэрэгжүүлэх тойрог эдийн засаг, батарейн хаягдал болон EPR системийн эхний баримт бичиг агуулдаг.

---

## Purpose / Зорилго

**English:**
To establish a responsible collection, reuse, and recycling system for batteries and other waste in Mongolia that ensures manufacturer accountability, proper data management, sustainable financing, infrastructure development, and promotes environmentally conscious consumer behavior.

**Монгол:**
Монголд батарей болон бусад хаягдлын хариуцлагатай цуглуулалт, дахин ашиглалт, дахин боловсруулалтын системийг үйлдвэрлэгчийн хариуцлагатай холбон, өгөгдөл удирдлага, тогтвортой санхүүжилт, дэд бүтцийн хөгжил болон байгаль орчноухугаарлаг хэрэглэгчийн зан төлөвийг дэмжүүлэх байдлаар үүсгэх.

## Core Concept / Гол Санаа

**English:**
EPR is not merely about waste management. It is a comprehensive framework integrating manufacturer responsibility, data governance, financial mechanisms, infrastructure development, and consumer behavior transformation into a unified system. The goal is to create accountability at every stage of the product lifecycle.

**Монгол:**
EPR бол зөвхөн хог хаягдлын тухай биш. Энэ бол үйлдвэрлэгчийн хариуцлага, өгөгдөл удирдлага, санхүүжилтийн механизм, дэд бүтцийн хөгжил, хэрэглэгчийн зан төлөвийн өөрчлөлтийг нэг системд хоорондоо холбосон иж бүрэн хүрээ. Зорилго нь бүтээгдэхүүний амьдралын мөчлөгийн бүх үе шатанд хариуцлагыг нэг болгох явдал юм.
